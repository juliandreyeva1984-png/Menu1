# Café Équilibre

Сайт в парижском стиле: считает норму калорий по росту и весу и составляет меню на день из продуктов, которые есть у вас дома.

Один файл `index.html`, без сборки и зависимостей. Шрифты подключаются с Google Fonts.

## Как работает

- Норма калорий считается по формуле Миффлина–Сан-Жеора с учётом активности и цели.
- Продукты добавляются и удаляются вручную, в каталоге около 70 готовых позиций.
- Список продуктов и параметры сохраняются в браузере (localStorage), на другом устройстве они не появятся.
- Расчёт ориентировочный и не заменяет консультацию врача.

## Публикация на GitHub Pages

1. Создайте репозиторий и загрузите `index.html` и `README.md` в корень.
2. Откройте Settings, затем Pages.
3. В разделе Build and deployment выберите Deploy from a branch, ветку `main` и папку `/ (root)`.
4. Через минуту сайт откроется по адресу `https://ваш-логин.github.io/название-репозитория/`.
